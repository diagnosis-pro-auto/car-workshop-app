# نظام متابعة صيانة السيارات

هذا التطبيق مبني باستخدام **Streamlit** ويسمح بمتابعة حالة السيارات في الورشة وتحديثها بسهولة.

## المتطلبات
- Python 3.8 أو أحدث
- تثبيت الحزم عن طريق:
  ```bash
  pip install -r requirements.txt
  ```

## التشغيل محلياً
بعد تثبيت المتطلبات شغِّل:
```bash
streamlit run car_tracker_advanced.py
```
سيفتح المتصفح تلقائياً على واجهة النظام وسيتم إنشاء قاعدة بيانات SQLite باسم `workshop.db` في المجلد الحالي.

## طريقة النشر
يمكن نشر التطبيق على [Streamlit Cloud](https://streamlit.io/cloud) أو أي خادم يدعم تشغيل تطبيقات Python. يكفي رفع السكربت مع ملف `requirements.txt` وسيتم تثبيت الحزم تلقائياً.

## خطوات الاستخدام السريع
1. سجّل الدخول باستخدام الحساب الافتراضي `admin`/`admin` أو `user`/`1234`.
2. أضف بيانات السيارة ورقم جوال صاحبها من تبويب **إدارة الورشة**.
3. حدّث حالة السيارة وأضف الملاحظات عند الحاجة.
4. يستطيع العميل الاستعلام عن سيارته من تبويب **استعلام العميل** بإدخال رقم السيارة أو الجوال.

## المميزات
- حفظ السجل الكامل لجميع التغييرات على حالة السيارة.
- تقارير وإحصائيات لأكثر العملاء وحالات السيارات الحالية.
- إمكانية ربط إشعارات واتساب لاحقاً عبر الهوك الموجود في الكود.
